# Scientific and reproducibility audit

The baseline is `tcc` commit `6a492fecc715e7b17780d31fa46382e24e642c34`. All historical artifacts retain their original contents.

| Finding | Consequence for this campaign |
|---|---|
| The standard Fourier path in `train.py::_transform` applies resize/tensor/normalization for non-RGB modes under conventional fine-tuning. The robust SRM campaign in `scripts/run_forensics_campaign.py` instantiates `RandomizedRobustAugment` at training. The five-seed RGB tables and conventional representation table describe different regimes. These paths establish a confound when comparing those runs; individual archive claims still require their original run configurations. | No causal Fourier/SRM comparison. New mechanism comparisons use identical within-backbone data, routes, backbone initialization, update count, selection, input budget and seeds. The clean comparator intentionally uses native exposure only. |
| Clean and degraded MFFI image scores can be joined, but an image-level join does not certify disjoint people or physical transmissions. The repository's DF40 investigation identifies 156 mislabeled real frames among 500 sampled local `cdf_reenactment` images. | Those results remain historical. No MFFI row, adapted local DF40 label, or previous paper threshold establishes a new external result. Source dev/cal use FF++; independent cohorts require verified visual labels and lineage. |
| Repeated views, partners, sessions, and seeds can exaggerate precision. Both labels can inadvertently be processed under different conditions. Some external detectors cannot score a mouth/face. | Split connected source–identity–session components, audit delivery settings, test one registered representative per cluster per label, preserve all views per draw and report related-recording sensitivity separately. The statistical output reports attempted and successfully scored cases. |
| Marginal false alarms can underestimate the chance of falsely flagging a genuine recording in one or more submissions. A recalibrator fitted to target outcomes can exaggerate apparent recovery. | Fit policies using private source folds. Calibrate at a guarded source operating point, freeze it and test the external any-copy budget. Independent external diagnostic quantiles provide an explicitly upper, potentially loose limit for deterministic route-specific monotone recalibration of the specified frozen comparator. |
| An unmatched shuffle, native floor fitted on model-selection data, same-detector policy changes, or different exposure budgets could mimic a correspondence gain. | Shuffled controls preserve marginal views and class/family structure, require cross-lineage matches and refine source quality/duration strata where feasible. The clean floor uses a distinct fit fold. The conventional source-selected detector also competes under the same shared threshold policy. Verify the observed optimizer updates and tail sample counts in training history. |
| Spatial preprocessing and historical model/library conventions can affect scores. | Score deployed end-to-end inputs and repeat the matched comparison with human-reviewed tracks at the same weights and thresholds. Released GenD and LipForensics have independent upstream parity tests. Audit uncovered an erroneous checkpoint envelope passed to the crop loader and a PIL/OpenCV grayscale discrepancy; corrections have regression coverage. The spatial cropper and landmark front end are registered study choices. The model parity test does not establish equivalence to each author's entire benchmark acquisition. |
| Concurrent SLURM array registration, stale prediction shards, post-staging changes or incompatible model files could invalidate a completed run. | Short blocking protocol lock; stage/per-run locks, atomically replaced checkpoints/receipts, Git/asset/config/input hashes, per-shard score reuse, pre-scoring seals on the actual tracked crops and annotation bytes, post-staging material validation and strict model construction prior to training. Replays reject incompatible output identities. |
| A pretrained or previously evaluated detector can have prior target exposure. Library validation cannot certify licences, ground truth or subject identity. | Public detector comparisons are conditional on their actual exposure histories. Restrict controlled mechanism claims to the newly matched retraining runs. Verify field metadata, receipt authenticity, pretrained provenance and cluster independence on server. Document acquisition sessions and any holdout family verified only against supervised source training. |

The confirmatory protocol registers a clean noninferiority margin of two percentage points and a five-point material gain against ordinary augmentation. Comparison or FPR intervals spanning the required margin are inconclusive. No run on synthetic clips establishes transfer to real forgeries. The server run must provide the effect sizes, uncertainty, failure cases, power and cohort replication needed to decide which claims survive.
