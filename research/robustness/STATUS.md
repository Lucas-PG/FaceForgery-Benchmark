# Research implementation status

Work continues on `robust-generalization` in the Lucas-PG fork only. See `import.json` for the immutable upstream snapshot and preserved explicability history. The imported upstream code and reported tables are not automatically validated experimental evidence.

The first implementation stage establishes canonical labels (0 real / 1 fake), signed manifest certificates, explicit group identities, exact prediction alignment, grouped uncertainty, and RGB–spectral complementarity analysis. A file hash is an integrity check, **not a cryptographic signature or proof of ground-truth correctness**; human label/provenance review remains necessary.

No GPU experiments, full image inference, new scientific scores, or claims of publication acceptance are part of the software build. Completed software checks and remaining execution responsibilities will be recorded in the final handoff.
